stemCAT - a desktop companion for Windows

Download the portable executable:
https://github.com/stemAGH/stemCAT/releases/latest

Double-click stemCAT.exe to run. No setup installer is needed.
Right-click the character or tray icon for settings and Quit.
Ctrl+Alt+L toggles click-through; Ctrl+Alt+P toggles privacy mode.

For screenshots, all characters, controls, privacy details, troubleshooting,
and source-build instructions, see README.md or:
https://github.com/stemAGH/stemCAT#readme

To build locally, run build.bat on Windows with .NET Framework 4.x.
